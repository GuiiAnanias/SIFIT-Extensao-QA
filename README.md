# SIFIT - Extensão QA

Trabalho individual da disciplina Extensão - Qualidade de Software (Sistemas para Internet - UniAlfa), 2º bimestre.

A proposta é testar manualmente o SIFIT, um sistema web de gestão para academias, e documentar o processo: levantamento dos requisitos, plano de testes, casos de teste, bugs encontrados e relatório final.

## Estrutura

```
SIFIT/
├── 1-Analise de requisitos.md
└── 2-plano de testes.md
```

## Andamento

- [x] Análise de requisitos
- [x] Plano de testes
- [ ] Cenários e casos de teste
- [ ] Execução dos testes e evidências
- [ ] Relatório de bugs e relatório final

## Como estou testando

Os testes são manuais, feitos direto no ambiente do sistema. Os casos de teste seguem o formato BDD (Dado / Quando / Então) e as evidências são gravadas em vídeo com a extensão Jam no Chrome. Para conferir se os dados foram gravados certo, uso o MySQL Workbench.
